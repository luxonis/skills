# Device readiness layers

Use the highest layer proven by direct observation:

- **Discovered:** a current tool reports a candidate device.
- **Reachable:** the selected device responds or opens.
- **Baseline-ready:** a minimal known-good path streams direct data.
- **Device-ready-for-plan:** the selected device executes the host or standalone path required by
  the current approved plan.

Do not promote metadata to runtime proof. In particular, managed OAK 4 device information does not
prove authentication, app build, container start, DepthAI pipeline start, or inspection.
