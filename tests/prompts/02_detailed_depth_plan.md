# Detailed new-POC case

The customer wants an OAK 4-D POC that measures cartons from 0.2 to 1.0 m wide on a conveyor.
Working distance is 1.5 to 2.5 m, cartons can be dark or glossy, speed is 0.7 m/s, target is at
least 20 FPS, and the result must be JSON over MQTT. The project contains ten representative
recordings and the broker schema. Accuracy should be evaluated against manually measured cartons.

Plan the POC. Do not implement it yet. Make the proposed OAK/host/MQTT data path and the design
decisions that need evidence easy to review.
